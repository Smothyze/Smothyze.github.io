Website Sales Honda – WordPress

Backend Developer | Team Project (3 Members)

  • Berkolaborasi dalam tim beranggotakan tiga orang untuk mengembangkan website penjualan kendaraan Honda berbasis WordPress.
  • Bertanggung jawab pada pengembangan backend dan fungsionalitas website menggunakan custom PHP snippets melalui plugin WPCode.
  • Mengembangkan fitur katalog kendaraan dengan fungsi sorting untuk mempermudah pencarian informasi mobil.
  • Mengimplementasikan fitur komparasi harga kendaraan untuk membantu pengguna membandingkan beberapa model.
  • Mengembangkan fitur simulasi kredit untuk menampilkan estimasi pembayaran berdasarkan konfigurasi kendaraan dan uang muka.
